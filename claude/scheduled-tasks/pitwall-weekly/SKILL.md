---
name: pitwall-weekly
description: Every Sunday at 10:00 (UTC+4): run the Pitwall skill on the last 7 days, write the notes, publish the report as a Claude artifact
---

Ты делаешь Максиму (говорит по-русски) еженедельный отчёт Pitwall: насколько эффективно он руководил своими параллельными агентами Claude Code за прошедшую неделю.

Инструмент: skill `pitwall`, установлен в `~/.claude/skills/pitwall` (symlink на `~/open-source/pitwall/skills/pitwall`). Сначала вызови skill `pitwall` и следуй его SKILL.md целиком: он описывает и запуск, и заметки, и как читать числа. Ниже только то, что важно для этого прогона.

1. Окно: 7 полных дней до сегодняшнего дня (значение по умолчанию, флаг `--days` не нужен).
   ```
   python3 ~/.claude/skills/pitwall/pitwall.py --json > ~/.claude/pitwall/pitwall.json
   ```
2. Прочитай JSON и напиши `~/.claude/pitwall/notes.json` по правилам SKILL.md: `week` (одно предложение, вердикт недели), `days` (по строке на каждый день), `hours` (по строке на каждый час, где была работа агентов), и обязательно `titles`: короткое английское название для каждой сессии из `sessions[]` по её `id`, не длиннее восьми слов. Все тексты в notes только на английском, без тире-эмдашей. Прежде чем писать заметки, открой два-три худших момента недели в транскриптах (`days[].events`, самые большие окна starvation и thrash) и назови механизм конкретно.
3. Отрендери:
   ```
   python3 ~/.claude/skills/pitwall/pitwall.py --notes ~/.claude/pitwall/notes.json
   ```
   Результат: `~/.claude/pitwall/report.html`. С первого повторного прогона в плитках появится сравнение с прошлой неделей из `~/.claude/pitwall/history.jsonl`; не трогай этот файл.
4. Опубликуй `~/.claude/pitwall/report.html` как Claude-артефакт (инструмент Artifact, файл как есть, favicon 🟠, description одной фразой: неделя и даты). Это отчёт с его собственными названиями сессий, публиковать без `--no-titles`; артефакт приватный.
5. Ответ по-русски, коротко, в порядке из раздела "Report back" в SKILL.md: заголовок с agent-hours и мёртвым временем, что уже получается хорошо (из `strengths`, с числом), одно изменение, которое окупится больше всего (`levers[0]` плюс механизм из транскриптов, как правило формирования задач, не "сосредоточься"), и ссылка на артефакт. Заметки из notes в ответе не повторяй.

Если сессий за неделю нет, скрипт завершится с ошибкой: тогда просто скажи, что неделя пустая, и ничего не публикуй.
